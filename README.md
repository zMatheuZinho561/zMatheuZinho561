## Projeto em destaque

### Sistema de Gestão Modular

Plataforma multi-tenant construída em **CakePHP + MySQL**, containerizada com **Docker**, com um dashboard de superadmin que:

- Ativa/desativa módulos por cliente (**NR-1** e **RH** atualmente)
- Cria empresas (clientes) sob demanda: um formulário dispara a criação automática de banco de dados e tabelas para a nova empresa
- Está em evolução para mover o controle de módulos ativos do front-end para o back-end, garantindo que módulos desativados nem sejam carregados no servidor

> Próximo passo: bloqueio de módulos direto na camada de back-end, hoje o controle só impede a exibição no front.
