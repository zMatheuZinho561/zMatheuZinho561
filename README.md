## Projeto em destaque

### Sistema de Gestão Modular

Plataforma **multi-tenant** em CakePHP + MySQL, rodando em Docker. Um dashboard de superadmin controla tudo:

- **Módulos por cliente** — NR-1 e RH ativos hoje, ativáveis/desativáveis por empresa
- **Provisionamento automático** — ao cadastrar uma nova empresa, o sistema cria banco de dados e tabelas dela sozinho
- **Em evolução** — movendo o controle de módulos ativos do front-end para o back-end, para que módulos desativados nem cheguem a carregar no servidor
